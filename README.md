## Overview

This is [Starkom][starkom]'s EVM verifier, a set of smartcontracts that verify Starkom proofs on the
Ethereum Virtual Machine.

This verifier only supports proofs over the [BlueSky prime field][bluesky] using the
[Keccak-256 hash backend][keccak256-backend];

> [!NOTE]
> This version of the package verifies proofs generated by version 12 of the
> [`starkom-plonk`][starkom-plonk] crate.
